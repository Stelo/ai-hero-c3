## Architecture Overview

**React Router v7 SSR** app with a service layer pattern. Routes handle HTTP concerns (loaders/actions); services handle all database queries.

- `app/routes/` — Route files: each exports `loader`, `action`, and default component
- `app/services/` — Pure functions for all DB queries, grouped by domain (e.g. `courseService.ts`, `enrollmentService.ts`)
- `app/lib/` — Utilities: session management, validation helpers, PPP pricing, markdown rendering
- `app/components/` — Reusable UI (shadcn/ui base components + custom)
- `app/db/schema.ts` — Single Drizzle schema file with all 18 tables
- `app/routes.ts` — Centralized route definitions

**Route types**: Generated by React Router — import from `./+types/route-name` (e.g. `import type { Route } from "./+types/courses"`).

## Auth

Cookie-based sessions (`cadence_session`). Use `getCurrentUserId(request)` from `lib/session.ts` to get the current user. Roles are `Student`, `Instructor`, `Admin`.

## Validation

Use Valibot (not Zod) for all schema validation. Use `parseFormData()` / `parseParams()` from `lib/validation.ts`.

## Database

SQLite via Drizzle ORM. The `db` instance is imported from `app/db/index.ts`.
